How do I download after I purchase?
  1. Pick Starter, Pro, or Elite on Pricing and finish Stripe checkout. Visa and major credit cards. We never see your card number.
  2. Stripe sends you back to Download. Log in if the page asks. The download button stays locked until this account has an active subscription.
  3. Click Download LapSimPro. That request goes through the subscriber check, then gives you LapSimPro-Setup.zip.
  4. On the Windows racing PC, extract the zip and run the installer.
  5. In iRacing, set Display Mode to Windowed or Borderless Windowed, then launch LapSimPro.

Same steps are on Get started. The subscription check itself is unchanged: a logged-in Download still confirms the plan before the installer link.

The download 404s. Where is the installer?

A 404 on lapsimpro.com/releases/LapSimPro-Setup.zip means the browser asked the website for a file it does not keep. Use either of these:

  1. Open https://lapsimpro.com/releases/. That page forwards you to the installer.
  2. Or save the Release asset directly: LapSimPro-Setup.zip.

If you are a subscriber, start from Download while logged in so the subscription check runs first. The file you receive is the same zip. If the browser says the download failed, blocked it, or saved an HTML page named like the zip, delete that file and use the releases page again.

I paid, but login or download still says I'm not subscribed.
  1. Log in on Log in with the email for this LapSimPro account. Email and password, or the magic link.
  2. Open Download again. Logged out, the button says Log in to download. Logged in without an active Starter, Pro, or Elite plan, it says Subscribe to download.
  3. If Stripe just returned you here with session_id in the address bar, stay logged in and reload Download. The page attaches that checkout to the account.
  4. Open Account. An active plan shows the plan name and a link to Download. “No active subscription” means this login is not entitled yet.

Checkout while logged in is the reliable path. If you paid and Account still shows no subscription, email support with the account email and the approximate time of payment. Do not send the card number, CVC, or full card details.

Windows SmartScreen warns that the installer is unsigned.

This build is not signed with a public code-signing certificate. Windows may show “Windows protected your PC” and say Microsoft Defender SmartScreen prevented an unrecognized app from starting. That dialog is expected for this installer.

  1. Confirm the file is LapSimPro-Setup.zip from Download or /releases/.
  2. Extract the zip, then start the installer from that folder.
  3. On the SmartScreen dialog, choose More info, then Run anyway.

Only do that for the LapSimPro installer you just downloaded from lapsimpro.com. Leave SmartScreen on for the rest of the PC. If Windows or the browser offers a different file name, or the zip will not extract, stop and email support.

The overlay won't start, or I can't see the HUD.
  1. Finish the installer, then launch LapSimPro on the same PC as iRacing.
  2. In iRacing: Options → Graphics → Display Mode → Windowed or Borderless Windowed. Exclusive fullscreen covers every overlay, so the HUD can be running and still be invisible.
  3. Until the sim connects, the HUD stays up and reads WAITING FOR IRACING. Start a session, then look again.
  4. Ctrl+Shift+O toggles click-through so you can drag the HUD. Ctrl+Shift+Q or Esc quits.

In the pits the cue goes to STANDBY once a reference is loaded. NO REFERENCE FOR THIS TRACK means this track and car have no catalog lap yet — it retries, and it will not paste another track’s markers onto this one. NO TRACK TITAN DATA only means the community time is missing. Brake markers still run from the package.

Cloud sync uses a LapSimPro device token from Account, stored at ~/.lapsimpro/session.json. The HUD can still draw without that file. Download itself stays tied to the subscription, not to the device token.

The sim stutters after I turn the overlay on.

LapSimPro is a separate display-only window. It does not inject throttle, brake, or brake bias, and it does not change iRacing’s frame limiter.

  • Keep iRacing in windowed or borderless, not exclusive fullscreen.
  • Close other overlays you are not using.
  • If the PC is already near its limit, lower iRacing graphics quality.
  • Leave the HUD click-through (Ctrl+Shift+O) while you are driving so it does not take clicks.

There is no phone line and no chat widget. Do not send card numbers or passwords.
