How it works

Drive. Overlay calls the mark. Board shows the time.

No exclusive fullscreen. No writing into the sim. The HUD sits on top of borderless iRacing and stays out of the way.

01

Borderless windowed

In iRacing: Options → Graphics → Display Mode → Windowed or Borderless Windowed. Exclusive fullscreen covers every overlay.

02

Launch the HUD

Run python -m iracing_coach live --desktop. Frameless, always-on-top, click-through. Ctrl+Shift+O to drag; Ctrl+Shift+Q to quit.

03

Chase the catalog + TT

Markers hot-reload for the session track. Pedal bars show the Garage 61 target. The status line stamps TT best when a public board matches.
