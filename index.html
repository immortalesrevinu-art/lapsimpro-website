Overlays

What the coach draws while you drive.

Five views are in the live coach when a reference matches your session. Standings, Relative, Delta, Track Map, and Fuel Calculator are coming soon. Every cue is display only.

Live

Coach overlay

Brake and throttle markers come from a pro fastest lap, and only for the exact track and car in your session. A different combo does not inherit those marks. The HUD draws on screen. It does not steer, brake, or change the car.

Preview the live aid

Live

REF vs YOU pedal graph

The pedal graph compares the reference trace with your brake and throttle. The fill is REF. A thin tick can show YOU. Both are display only, including when the loaded lap is a Garage 61 reference. The bars never drive the pedals.

Live

Live speed comparison

While a matching reference is loaded, the coach shows your live speed against that lap. It is a comparison on the HUD, not a pace estimate invented for a combo that has no reference.

Live

Per-corner brake bias cues

Bias cues call the reference brake bias for the corner you are approaching. They are text on the overlay. LapSimPro does not write brake bias into iRacing.

Live

Auto reference on a new track

When you join a new track, LapSimPro pulls reference data for that session’s track and car if a match exists. If it does not, the HUD says there is no reference. It will not apply another circuit’s lap.

How a lap is chosen

Match the session, or show nothing.

01

Exact track and car

Markers and the pedal reference load only when the session combo matches the reference lap.

02

Display only

The overlay never injects throttle, brake, or brake bias into the sim.

03

No borrowed lap

If this track has no reference, LapSimPro says so. It does not reuse a sample from another circuit.
