Get started · lapsimpro.com

One command over borderless iRacing.

Clone the overlay package, install the live extra, then run the desktop HUD. This page is the LapSimPro on-ramp at lapsimpro.com — full detail still lives in the repository README. Commands still use the iracing_coach package name.

Open GitHub repo Preview the HUD
Borderless windowed is required. Exclusive fullscreen covers every overlay, including this one. In iRacing go to Options → Graphics → Display Mode → Windowed or Borderless Windowed.
1

Clone the overlay

Python 3.11+ on the Windows racing PC. The package lives in this repo.

GitHub 
git clone https://github.com/immortalesrevinu-art/iracing-coach-overlay.git
cd iracing-coach-overlay
py -3 -m venv .venv
.venv\Scripts\activate
pip install -e ".[live]"
2

Token (live catalog)

Create a Garage 61 personal access token and put it in .env as GARAGE61_TOKEN. Demo mode does not need a token.

.env 
copy .env.example .env
notepad .env

Never commit .env. The overlay never ships credentials.

3

Go live

Start iRacing (practice or race), then launch the frameless HUD.

Live desktop HUD 
python -m iracing_coach live --desktop

Default for live is already the desktop window. --desktop makes that explicit. Use --web if you want the browser HUD instead.

4

Drive

Ctrl+Shift+O toggles click-through so you can drag the HUD. Ctrl+Shift+Q or Esc quits. Catalog + Track Titan lookups happen in the background.

Optional extras
python -m iracing_coach demo
python -m iracing_coach demo --desktop
python -m iracing_coach catalog --refresh
python -m iracing_coach tracktitan --track "Barcelona" --car "296"
python -m iracing_coach setups sync

What you should see

Waiting, then armed, then BRAKE NOW.

No sim yet

HUD stays up and shows WAITING FOR IRACING until the SDK connects.

Pits / garage

STANDBY once a reference is loaded, so the cue does not pulse on pit speed.

No lap for this track

NO REFERENCE FOR THIS TRACK — retries. It will not apply the Laguna sample to Barcelona.

TT missing

NO TRACK TITAN DATA in the status line. Garage 61 markers still work.
