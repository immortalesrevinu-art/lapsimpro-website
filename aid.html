Animated mock · real HUD is PySide6 on Windows or the browser demo

Brake markers

Next name, countdown in metres, PREPARE then BRAKE NOW. Markers come from the local catalog / Garage 61 fastest visible lap. Wrong-track fallback to Laguna is disabled in live mode.

Pedal targets

Brake bar left (red), throttle bar right (green). Fill is the reference pedal_trace at current LapDistPct. The overlay never writes pedals into iRacing.

Bias prompts

BIAS FWD / REAR / HOLD plus optional target percent. Display-only. You press your own in-car bindings if you want to move bias. Automating mid-race bias is out of scope.

Track Titan best

Public leaderboard JSON, no API key. HUD shows TT best 1:41.218 or NO TRACK TITAN DATA. Times only — Garage 61 still owns brake telemetry.

Desktop window

Built to live over borderless iRacing.

Click-through

Default: mouse and keys go to the sim. Ctrl+Shift+O toggles so you can drag the HUD. Ctrl+Shift+Q or Esc quits.

Waiting / standby

If iRacing is not up yet: WAITING FOR IRACING. In garage or pits: STANDBY, so BRAKE NOW does not flash on the dummy grid.

Track-aware bind

Reads TrackID / car from IRSDK, matches Garage 61, hot-reloads markers. No reference? HUD says so and retries. It will not paste Laguna onto Barcelona.

Browser fallback

python -m iracing_coach live --web or demo opens the same cues in a local page at 127.0.0.1 — useful off the racing PC.
